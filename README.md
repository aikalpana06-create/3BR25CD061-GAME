# Rocket Run 🚀

Pilot your ship through the debris field. Dodge asteroids, harvest energy cells, and survive the ever-accelerating void!

## 🎮 Play the Game

[Click here to play Rocket Run live](https://rocket-run-phi.vercel.app)

## 🚀 Game Overview

**Rocket Run** is an action-packed web game where you navigate your rocket ship through space while avoiding hazardous asteroids and collecting energy cells.

### Gameplay Rules
- **Collect Glowing Energy Cells:** Earn points by harvesting energy cells as you navigate through space.
- **Dodge Asteroids:** Avoid collisions with floating asteroids or lose a life.
- **Survive:** Try to survive for as long as possible as the game speeds up!

## 🎮 Controls

- **Keyboard:** Use `W` / `S` or `Up Arrow` (`↑`) / `Down Arrow` (`↓`)
- **Mouse / Touch:** Move your mouse cursor or touch screen to steer your rocket ship.
